# Convite de Casamento — Jain & Tati

Página digital responsiva para o convite de casamento civil.

## Arquivos

- `index.html` — página principal
- `style.css` — visual e animações
- `script.js` — música, rolagem e botão Pix
- `assets/convite.jpeg` — arte fornecida
- `assets/musica.mp3` — música fornecida

## Como testar

Abra `index.html` no navegador.

## Como publicar no Render

Crie um novo Web Service ou Static Site apontando para este projeto.
Para um Static Site, publique a pasta do projeto e use `index.html` como página inicial.

## Observação sobre a música

A página foi preparada para tocar o arquivo local `assets/musica.mp3` após o visitante tocar em "Abrir convite".
Verifique os direitos de uso da música caso o convite seja publicado publicamente.
